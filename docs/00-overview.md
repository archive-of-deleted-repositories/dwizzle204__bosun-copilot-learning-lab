# 00 - Overview

This lab teaches a full local setup on Ubuntu (desktop or headless server):
- Node.js + npm
- GitHub Copilot executor path (via GitHub CLI auth)
- GitHub CLI auth (OAuth)
- Optional Codex CLI auth (interactive use)
- Bosun install + setup
- Optional Telegram notifications
- Optional `systemd` service
- Full cleanup

## Safety Notes

- Treat this as a test environment.
- Keep secrets in local `.env` files only (never commit).
- Telegram is for lightweight status notifications only.
